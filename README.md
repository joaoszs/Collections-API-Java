## 📖 Sobre o projeto

Repositório desenvolvido durante o **Bootcamp Santander**, com foco no estudo e na aplicação prática do **Java Collections Framework**.

O projeto reúne exercícios e implementações voltados à manipulação de estruturas de dados, explorando suas características, funcionalidades e aplicações no desenvolvimento de software com Java.

## 🎯 Objetivos

- Aprimorar os conhecimentos na linguagem Java.
- Compreender o funcionamento do Java Collections Framework.
- Desenvolver habilidades na manipulação de estruturas de dados.
- Consolidar conceitos de Programação Orientada a Objetos (POO).
- Aplicar boas práticas de organização e desenvolvimento de código.

## 🧠 Conceitos abordados

| Conceito | Descrição |
| --- | --- |
| Collections Framework | Conjunto de interfaces e classes para manipulação de coleções. |
| List | Estruturas ordenadas que permitem elementos duplicados. |
| Operações básicas | Inclusão, remoção e consulta de elementos. |
| Iteração | Percurso e manipulação dos elementos de uma coleção. |
| POO | Aplicação de classes, objetos, métodos e encapsulamento. |
